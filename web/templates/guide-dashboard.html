Example: one promotion program

The item monthly-promo has the slug /monthly-promo for the home card, /monthly-promo-threads for Threads, and /monthly-promo-instagram for Instagram. Each slug has its own analytics. The program status only needs to change once, on the item.

02

Create a plain link

For a resource, article, or link that does not need to be managed as a program yet.

  1. Open Links, then choose Add link.
  2. Fill in the slug and destination URL. For example, the slug learn-go produces a short address ending in /learn-go.
  3. Add a description and category. Fill in Provider, Channel, and Campaign if you want to compare where traffic comes from.
  4. Save, then copy and test the short link. An active link that is not connected to an item appears in the public link catalog.

If the destination changes, edit the URL in Links. Keep the slug you already shared so the old address keeps working.

03

One program, many channels

For a referral, promotion, or product with one public card and several distribution links.

  1. Open Catalog → Add item. Choose the item type: Product, Referral, Service, Resource, Article, or Project. Fill in the name, provider, description, category, and image (upload a PNG/JPEG/WebP up to 5 MB, or enter a URL).
  2. Fill in the card slug and destination URL. This slug is used when a visitor selects the card on the home page or in the catalog.
  3. Set Program status: Active. Set the start date and end date if there is a schedule. Tick Show the card while the program is available.
  4. Save the item, then use Add a channel link. Create a different slug for each channel, for example monthly-promo-threads with the channel threads.
  5. Fill in Campaign when useful, for example october-review. A channel URL can match the card or use a URL specific to that channel.
  6. Share each slug on its channel. Use the channel and campaign filters in the item editor to find and compare its links.
Provider

Who provides or sells it, for example Shopee.

Channel

Where the link is shared, for example Threads, a blog, or email.

Campaign

A specific promotion or placement, for example an October review.

The Use for card button selects the slug used by the public card. Every other slug stays available and is counted separately.

04

Already shared the link? Reuse the slug

Move its management to an item without recreating the link or losing existing analytics.

  1. If the program has no item yet, open Add item and tick Use an existing link.
  2. Enter the old slug as the card slug, for example monthly-promo. Its destination URL and click history are kept.
  3. To attach another slug to an existing item, open its editor, fill in Connect an existing link, then choose Connect link.
  4. Check the tracking links list. An attached slug follows that item program status, including the notice when the program has ended.

Only active links that no other item owns can be attached. Existing channel and campaign values are kept. Once connected, the link leaves the separate link catalog and is managed through the item card.

05

A referral or promotion has ended

The short address is still useful for explaining the change to people arriving from an older post.

  1. Open the program item. Set Program status: Ended; use Paused / under review while the outcome is still being checked.
  2. Fill in the message for visitors with the benefit that no longer applies, for example a $5 referral credit. Add the official source URL and the date when known.
  3. Choose Show a notice (recommended). Fill in the provider website / fallback URL if you want a button to a provider site that is still relevant.
  4. Save, then test the card slug and one channel slug. The card leaves the active catalog; every connected active slug shows the same notice.
  5. Update older posts that can still be edited. Use the notice views count to see which channel still brings visitors.
What happens when someone opens a slug?
Program statusActive link behavior
ActiveRedirects to each slug destination while its schedule is active.
Paused / under reviewTemporary notice; the card is hidden.
Not startedA not-started notice until the start date.
ExpiredThe chosen notice or redirect, after the end date passes.
EndedThe chosen notice or redirect, immediately after saving.

The end date covers that entire day in the reporting time zone. The status change date and last verified are notes only; neither schedules an automatic change. Program checks are still done manually.

Choose automatic redirection only when the fallback URL really serves the visitor purpose. Paused or not-yet-started programs always show a notice. Older items that already have a fallback URL keep the redirect behavior when updated; check the option while editing.

06

Read the promotion results

Use consistent labels so comparisons stay clear.

  1. Open Analytics and choose a period. Use category to narrow the data.
  2. Choose a breakdown by provider, channel, campaign, or link to answer different questions.
  3. Open a single link details page to see daily clicks and traffic sources. Direct / unknown means the request carried no source information.
  4. For an inactive program, check notice views in the Catalog. That number is separate from redirect clicks in Analytics.

Redirect clicks are not unique people, sign-ups, purchases, or referral credit. Opening the website button on a notice does not add a redirect click. The all time period has no trend comparison.

The Export menu in Links provides a JSON/CSV catalog and a daily click report. Use the daily report to inspect click distribution on a specific date.

07

Set up the site and home page

Settings controls the global appearance; the Catalog controls each card content.

  1. Open Settings → Site identity to change the site name and description.
  2. In Home & services content, change the home label, title, and description, plus the services section title and description. This text appears on the public page without changing code.
  3. In Public features, choose the Full catalog, Bio link, or Link shortener only mode, or tick features individually: home page, catalog, services, articles, projects, resources, profile, support button, contact button, and favorites. A disabled feature leaves the navigation and its URL returns 404, but short slug redirects keep working.
  4. In Logo & favicon, upload a PNG/JPEG/WebP (up to 5 MB) or enter the logo URL and favicon URL (an HTTPS URL or local path; SVG through a URL). An upload replaces the URL. The logo appears on the public site and in the admin. An empty favicon follows the logo; without either, the default icon follows the public accent.
  5. In Profile & social links, set the avatar (empty uses the logo) and optional social links. The short description is used as the bio. Trakteer, Ko-fi, and Buy Me a Coffee appear as support buttons; other links appear as icons. The row is hidden when empty.
  6. In Contact button, configure the floating button that appears on public storefront pages. Set the bubble title and an optional short message, then add channels with + Add channel: choose an icon, enter the URL (for the Email icon, just the email address), and an optional label. Selecting a channel opens its app or site. The button only appears when the floating contact button feature is enabled and at least one channel is filled in; leave every channel empty to hide it.
  7. In the Catalog, the Article item type shows a card in the home Reading section and on the Articles page; the card opens the article URL directly and has no favorite button.
  8. The Project item type shows a card in the home Portfolio section and on the Projects page; the card opens the project URL directly and has no favorite button.
  9. In Referral disclosure, write the affiliate note that appears in the catalog.
  10. In SEO & sharing, set the SEO title, SEO description, share image URL (or upload a 1200 × 630 PNG/JPEG/WebP), and the public address. Automatic preview per Catalog item builds the share card from the item title, description, and image.
  11. In Featured items, enable the featured row on the home page and choose 1–3 cards.
  12. On each item, tick Add to featured and set the display priority; a higher value appears first.
  13. In Display colors, choose public and admin accents and backgrounds separately. Use a light background with a contrasting accent.
  14. Check the public home page. The item must be active, within its schedule, have an active card link, and be allowed to appear. Visitors can save cards to Favorites (stored in their own browser).

So contact clicks count in Analytics and the number stays off the page, create a link in Links (for example the slug wa to https://wa.me/62…) with Channel: contact, then use its short link as the contact channel URL, for example https://example.com/wa. Links with the contact channel do not appear in the public link catalog. Email cannot go through a slug because a slug destination must be an http(s) link.

Visitors scroll the featured row manually and it is not repeated in the home grid. The home grid shows at most six cards and six links; the Services, Articles, and Projects sections show their own cards with a View all button. The full list is in the catalog and the link catalog. In the public catalog, the search and category/provider filters carry across pages; saved cards appear on the Favorites page and stay in the visitor browser.

08

Things that are easy to mix up

These three controls do different things.

How are Show card, Paused, and disabling a link different?

Show the card in the Catalog only hides the card; the slug still follows the program status. Paused on a program shows a notice on every active slug. Pause on a link in Links disables that single slug, so visitors get a 404.

Why is my item not on the home page?

Check the active status, the start and end dates, the Show the card checkbox, and whether the card link is active. If all of that is correct, the card may be in the featured row or beyond the first six grid cards. Open the Catalog for the full list.

Where do I change the destination for one channel?

Edit that slug URL in Links. Changing one URL does not change another slug destination. If that slug is used as the card link, the public card destination changes too. An item description, category, and provider are also separate from the metadata of connected links; edit each link metadata from the Links page.

If I have hundreds of slugs, do I need hundreds of notices?

Fill in the notice once on the parent item. Every connected active slug uses it. Different programs have their own item data with the same page template.

The program is active again. Do I need new links?

Set the program status back to Active, check the schedule, then test the old slug. If the end date has passed, update it. Reactivate any links you disabled. Click history is kept.

Can I delete a link I no longer use?

For a link you already shared, keep the slug and use the program status or pause the link as needed. Deleting a link also deletes its click history. Changing the slug makes the old address stop working.

Why is the contact button missing from the public page?

Make sure the floating contact button feature is enabled in Public features and at least one channel is filled in under Contact button (rows with an empty URL are ignored). For the Email icon, just enter the email address. After CSS or JS changes the asset version changes automatically, so you do not need to clear caches manually.

Start with Links for a simple link, or Catalog for a program that needs to be managed as a whole.
