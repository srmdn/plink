# Analytics backlog

Catatan ini menyimpan opsi lanjutan yang sengaja ditunda dari release analytics
dashboard saat ini. Fitur inti tetap fokus pada pengelolaan link, ranking
provider, dan pembacaan performa berdasarkan slug.

## Ditunda

1. **Trend yang kontekstual** — sembunyikan kolom Trend ketika filter periode
   berada di `all`, karena tidak ada periode pembanding yang bermakna.
2. **Bulk edit metadata** — ubah provider, channel, campaign, atau kategori
   untuk beberapa link sekaligus.
3. **Status strategi promosi** — tambahkan status manual `push`, `observe`, dan
   `pause` agar ranking bisa langsung menjadi daftar kerja promosi.
4. **Conversion dan revenue tracking** — hubungkan klik dengan conversion,
   komisi, dan revenue supaya ranking tidak hanya berdasarkan traffic.

Item-item di atas bukan bagian dari release deployment ini dan akan dievaluasi
setelah dashboard dipakai dengan data produksi.
